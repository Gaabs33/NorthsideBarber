# Northside image guide

The project uses the following nine local editorial photographs. They are the images referenced by `index.html`:

| Filename | Use | Current visual role |
| --- | --- | --- |
| `hero-barber-tools.jpg` | Hero | Dark editorial barbering scene / tools |
| `exterior-barbershop.jpg` | About or Visit | Independent Brooklyn-style storefront |
| `interior-barbershop.jpg` | Visit | Chair, mirror and warm interior |
| `haircut-fade.jpg` | Gallery | Close fade detail |
| `haircut-classic.jpg` | Gallery | Clean classic haircut |
| `beard-trim.jpg` | Gallery | Beard trim or finished beard |
| `barber-working.jpg` | Hero / Gallery | Barber working documentary-style |
| `textured-crop.jpg` | Gallery | Modern textured crop |
| `waiting-area.jpg` | About / Gallery | Waiting area, coffee or counter detail |

All nine assets were generated for this project and copied into this directory. Replace them only with final photography that preserves the same subject, crop and visual tone.
